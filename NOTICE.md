# Credits

Sudo Chuck Check is a project by s3pp3ku, a computer enthusiast rather than a
programmer, made with help from AI tools. Its [history](HISTORY.md) records the
idea, the earlier Groot signature, and the reworking into the current banner.

The original Groot signature was found in a Reddit thread years ago. The thread
and author are currently unknown. `history/groot-original.zsh.txt` preserves the
saved signature, and `docs/images/groot-banner.png` recreates its output. These
historical materials are attributed to that unidentified source and are not
claimed as original project work or relicensed under this project's MIT grant.
Contributions identifying the original thread are welcome.

The idea was inspired by Paul Hocker's Omarchy Chuck Norris bar plugin:
https://github.com/paulhocker/omarchy-plugin-chuck
Marketplace: https://plugins.omarchy.org/plugin.html?id=paulhocker.omarchy-plugin-chuck
This companion's code and sprite are independent of that plugin.

Both banner PNGs are screenshots of the project's HTML recreations. They are
labelled as such; neither is claimed to be a historical desktop capture.

`jokes.txt` is copied from the Oh My Zsh `chucknorris` plugin:
https://github.com/ohmyzsh/ohmyzsh/tree/master/plugins/chucknorris

Oh My Zsh copyright and MIT license are preserved in `licenses/oh-my-zsh-MIT.txt`.
The copy contains 284 fortunes and is distributed unmodified.

`chuck-norris.png` is an AI-generated pixel-art sprite made with OpenAI's built-in
image tool. The generation prompt is recorded in `image-prompt.txt`. The project
permits use and redistribution of this supplied asset to the extent it holds rights.

This is an independent community customization, with no affiliation with or
endorsement by Chuck Norris, Omarchy, or Oh My Zsh.
